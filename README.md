# Order Trends and Business Analysis Dashboard | Power BI

## Project Overview

This project uses Microsoft Power BI to analyze sales revenue, order trends, product performance, and customer and employee performance. Interactive dashboards help transform transactional data into business insights that support data-driven decision-making.

## Business Objectives

- Analyze sales revenue and profitability.
- Identify high- and low-performing products.
- Understand sales and order trends over time.
- Analyze customer and employee performance.
- Support business planning through data-driven insights.

## Tools and Technologies

- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Data modeling and relationships
- GitHub for project documentation and portfolio presentation

## Dataset

This project uses an AI-generated synthetic sample dataset for learning and portfolio demonstration purposes. It does not represent actual company transactions.

Tables included:

- Customers
- Departments
- Employees
- OrderDetails
- Orders
- Product
- DateTable
- MeasureTable

## Data Preparation and Modeling

- Reviewed data types and data quality.
- Organized descriptive data into dimension tables.
- Used a fact table to store transactional data and foreign keys.
- Established relationships between related tables.
- Organized DAX measures in a separate measure table.

The model uses a hybrid dimensional structure with a snowflake-style arrangement of related tables.

## Dashboard Pages

### 1. Executive Overview
Summarizes business performance through KPI cards, sales trends, and overview charts.

### 2. Product Performance
Supports comparisons of product sales and profitability.

### 3. Customer & Employee Performance
Provides insights into customer-related metrics and employee performance.

### 4. Product Details
Displays product metrics, including sales revenue, quantity sold, orders, and trends over time.

## Key Finding

Total sales revenue was highest in October 2025 and lowest in November 2025.

**Business implication:** This decline highlights the need to investigate changes in order volume, average order value, product mix, pricing, or promotional activity.

## Business Recommendations

- Compare October and November order volumes to investigate the revenue decline.
- Review product-level sales and profitability.
- Monitor sales trends to support demand forecasting and inventory planning.
- Use customer and employee performance insights to identify areas for further analysis.

These recommendations should be validated through additional analysis before business decisions are made.
